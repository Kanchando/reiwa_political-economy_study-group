## 🎨 特長・スマホファースト設計（Mobile First UI）

- **Zero-Build Architecture**: 純粋な HTML5 / CSS3 / Vanilla JavaScript。ビルド不要で、ファイルをダブルクリックするだけでそのままブラウザで動作します。
- **モバイルファースト最適化**:
  - **片手操作対応の固定ボトムナビ**: 画面下部にすりガラス調（Glassmorphism）のフロートナビ（🗺️ 地図 / ⏳ 年表 / 📚 一覧）を常駐。
  - **横スワイプ＆クイック地域チップ**: 地図と年表は左右にスイスイ横スクロール可能。上部の地域ピル（🇯🇵 日本 / 🇺🇸 米国 / 🇷🇺 ロシア / 🇨🇳 中国 / 🇲🇳 モンゴル / 🏛️ ローマ）をタップすると、地図が自動でその地域へスムーズにスクロールし、即座に詳細が開きます。
  - **ボトムシート型ポップアップ（Bottom Sheet）**: スマートフォンでは画面下部からスッとカードが持ち上がり、指1本でタップしやすい大きなボタンで資料へジャンプできます。
  - **レスポンシブ・カードグリッド**: スマホでは押しやすい1カラム、PC・タブレットでは2〜3カラムに自動適応。
- **世界地図ナビゲーション**:
  - 各国・地域（日本、米・イラン・中国、ロシア、モンゴル帝国最大版図、ローマ帝国最大版図、アメリカ）を識別カラーで色分け。
  - 歴史的偉人（トランプ、プーチン、吉田茂、カエサル、チンギス・カン、毛沢東）の可愛いイラストを配置。
- **インタラクティブ年表**:
  - 前1600年〜現代（2026年）までの歴史的スケールを歪みなく表示するピースワイズ時間軸。
  - すっきりとした帯（バー）をタップすると詳細とリンクを確認できます。

## 🚀 閲覧方法

### 1. ローカルで直接閲覧
`index.html` を任意のブラウザ（Chrome, Safari, Edge等）にドラッグ＆ドロップして開きます。

### 2. GitHub Pages での公開
本フォルダ（`politics-study`）をGitHubリポジトリにプッシュし、Settings > Pages で `main` ブランチの root を選択することで即座にWeb公開できます。
